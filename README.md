# MIDQ

MIDI 精确转换为按键精灵 Q 脚本的单页工具。

本站为闭源发布：页面内仅含界面的静态资源与加密后的转换核心。核心逻辑以 AES-256-GCM 密文分发，
需使用许可密钥解封；任何修改或篡改都会导致完整性校验失败而拒绝运行。

进入方式：
1. 每次打开页面都先停在密钥页，不会自动跳过；校验通过后才进入工具；
2. 首次验证时勾选「在本机记住 30 天」，本机会保存一条带 SHA-256 签名的许可记录（只存混淆口令与到期时间，不含明文，并绑定本机设备指纹）；
3. 30 天内重开页面，密钥页顶部会出现快捷许可卡：显示尾号掩码、剩余天数与到期日，点「直接进入」即可免输口令；
4. 想换用别的密钥，点「改用其他密钥」展开输入框，新密钥验证成功后会覆盖旧记录；
5. 许可记录一旦被手动篡改（例如改到期时间），签名立即不符，记录被清除并退回输入框。

功能概览：
1. 单曲 / 批量转换，Delay 按累计时间轴反推，长曲逐组对齐（实测 2185 音符最大偏差 0.5 ms）；
2. 自动识别原曲调号与调式：优先读取 MIDI 文件内的调号元事件，缺失时按音级时值加权 + 低音根音加成的
   Krumhansl-Schmuckler 相关分析推断，输出大调/小调、相关度、领先值与置信度；离线合成样本 96/96 命中；
3. 标准调号移调（C、♯C/♭D、D … 共 25 档），以识别出的原调为基准，只改音高不改时间轴；
4. 速度预设 0.5×–2×、延时分段、时间量化、最小间隔与起始延迟；
5. 批量偏差可视化与 19 列明细 CSV；黑键坐标左上角标注 X / Y；
6. 主题切换持久保存、动态点阵背景、调号轮盘与音域条等可视化；
7. 调号轮盘随识别结果实时切换：识别出原调后中心显示该调、对应扇区高亮；选择非原调时，原调扇区额外以虚线环定位，避免看错基准；
8. 点「移除」一键复位：顶栏状态带、原调芯片、轮盘与音阶条、全部转换参数、结果卡与下载按钮同时回到初始态，不留上一首曲子的痕迹；
9. 视图切换为 320 ms 单层入场（透明度 + 4px 微位移，cubic-bezier(.16,1,.3,1)），卡片入场 8px、提示条同曲线，顶栏改为不透明底色以避免大面积模糊导致的掉帧；
10. 移动端导航自适应排布，390 px 宽无横向溢出、无横滑条。

安全措施（多层）：
1. 核心以密文分发，口令经 PBKDF2-SHA256 派生后解封，密钥只在本机内存中使用；
2. 解封后校验明文 SHA-256 与构建时指纹，不符即拒绝运行；
3. 核心载入后立即抹除全局引用，并周期性校验函数指纹，被替换即终止会话；
4. 启用 Content-Security-Policy：禁止外链脚本、外部对象与表单提交，仅允许本站资源与 GitHub API 连接；
5. 拦截 F12 与开发者工具快捷键，第 3 次按下 F12 弹出安全警告（可选择继续或终止会话）；
6. 检测开发者工具控制台与可视区域异常，命中即清空核心并锁屏；
7. 未解锁状态下强行改 DOM 显示应用会被自动回滚；
8. 安全监测在密钥页即生效，未解锁也计数与拦截；窗口最小化/切后台不会误判；
9. 拦截 Ctrl+P（打印/另存 PDF）、Ctrl+S（保存网页）、PrintScreen 截图，并阻止页面拖拽导出；
10. 检测 iframe 嵌入，被第三方页面套用时立即终止显示，避免被仿站骗取密钥；
11. 站点策略文件（security.json）可下发口令吊销与设备限制清单，策略更新后立即生效；
12. 启用 Permissions-Policy：禁用摄像头、麦克风、定位、支付、USB、串口、HID、剪贴板读取与屏幕捕获，压缩能力面；
13. 30 天许可记录签名绑定本机设备指纹，换机、换浏览器或改指纹都会立即失效并要求重新验证。
