本站为闭源发布：页面内仅含界面的静态资源与加密后的转换核心。核心逻辑以 AES-256-GCM 密文分发，
需使用许可密钥解封；任何修改或篡改都会导致完整性校验失败而拒绝运行。

安全措施（多层）：
1. 核心以密文分发，口令经 PBKDF2-SHA256 派生后解封，密钥只在本机内存中使用；
2. 解封后校验明文 SHA-256 与构建时指纹，不符即拒绝运行；
3. 核心载入后立即抹除全局引用，并周期性校验函数指纹，被替换即终止会话；
4. 拦截 F12 与开发者工具快捷键，连续 3 次按下 F12 弹出安全警告并终止会话；
5. 检测开发者工具控制台与可视区域异常，命中即清空核心并锁屏；
6. 未解锁状态下强行改 DOM 显示应用会被自动回滚；
7. 安全监测在密钥页即生效，未解锁也计数与拦截；窗口最小化/切后台不会误判；
8. 拦截 Ctrl+P（打印/另存 PDF）、Ctrl+S（保存网页）、PrintScreen 截图，并阻止页面拖拽导出；
9. 检测 iframe 嵌入，被第三方页面套用时立即终止显示，避免被仿站骗取密钥。
