## 进入方式

1. 每次打开页面都先停在密钥页，不会自动跳过；校验通过后才进入工具。
2. 首次验证时勾选「在本机记住 30 天」，本机会保存一条受保护的许可记录，仅用于下次免输口令。
3. 30 天内重开页面，密钥页顶部会出现快捷许可卡：显示尾号掩码、剩余天数与到期日，点「直接进入」即可免输口令。
4. 想换用别的密钥，点「改用其他密钥」展开输入框，新密钥验证成功后会覆盖旧记录。
5. 许可记录一旦被手动改动（例如改到期时间），校验立即不符，记录被清除并退回输入框。

## 功能概览

1. 单曲 / 批量转换，Delay 按累计时间轴反推，长曲逐组对齐（实测 2185 音符最大偏差 0.5 ms）。
2. 自动识别原曲调号与调式：优先读取 MIDI 文件内的调号元事件，缺失时按音级时值加权 + 低音根音加成的
   Krumhansl-Schmuckler 相关分析推断，输出大调/小调、相关度、领先值与置信度；离线合成样本 96/96 命中。
3. 标准调号移调（C、♯C/♭D、D … 共 25 档），以识别出的原调为基准，只改音高不改时间轴。
4. 速度预设 0.5×–2×、延时分段、时间量化、最小间隔与起始延迟。
5. 批量偏差可视化与 19 列明细 CSV；黑键坐标左上角标注 X / Y。
6. 主题切换持久保存（浅色为默认）、动态点阵背景、调号轮盘与音域条等可视化。
7. 调号轮盘随识别结果实时切换：识别出原调后中心显示该调、对应扇区高亮；选择非原调时，原调扇区额外以虚线环定位，避免看错基准。
8. 点「移除」一键复位：顶栏状态带、原调芯片、轮盘与音阶条、全部转换参数、结果卡与下载按钮、精度调优面板、脚本编辑器与结果标签页同时回到初始态，不留上一首曲子的痕迹。
9. 视图切换为 320 ms 单层入场（透明度 + 4 px 微位移，cubic-bezier(.16,1,.3,1)），卡片入场 8 px、提示条同曲线；顶栏改为不透明底色，避免大面积模糊造成的掉帧。
10. 帮助页「安全态势」面板：深色常驻视觉锚点，状态砖级联入场、扫描线与在线呼吸点均按 reduced-motion 偏好自动收敛。
11. 移动端导航自适应排布，390 px 宽无横向溢出、无横滑条。
12. 帮助页「本机环境」卡：读取操作系统、浏览器版本、屏幕与缩放、逻辑核心、内存与显卡厂商；全部在本机完成，不写入许可记录、不上传，尺寸变化时自动刷新。
13. 「安全态势」卡随主题换色：默认主题为紫 / 粉 / 玫红混合，蓝海、樱粉各自成调，第 4 套浅紫才使用单一紫调。
14. 「曲谱试听」工作台：五线谱、简谱、钢琴卷帘与离线分析四个视图；载入 MIDI 后即时生成，不需要转换即可预览。
15. 试听使用用户提供的 VSL STEINWAY & SONS D-274 SF2 抽取的 30 个键位锚点，按最近键移调、力度决定增益与低通；音频严格按原始 MIDI 时间轴调度，不叠加转换页速度倍率。
16. 真实试听进度条与时间码、暂停 / 继续 / 停止 / 静音 / 音量、播放与停止热键可改（默认 Home / F12，保存在本机）。
17. 谱面逐音滚动高亮：播放到哪个音，五线谱符头与简谱数字同步变色；点击谱面音符即回放该音组并弹出音名、组号、时刻与音长。
18. 离线 AI 分析：演奏密度、平均和声、平均力度、音域跨度四项 KPI，时间密度、音级分布、力度分布、和声规模四张 Canvas 图表；全部由原始事件与本地规则计算，明确标注非生成式模型。
19. 长曲自适应：按音符密度自动切换每页 2 / 4 小节（示例长曲 2 小节/页、57 页），播放时自动翻页，也支持手动翻页。
20. 黑键坐标实时写入本机并在整页重载后自动恢复；坐标改动 500 ms 后自动重转，键位预览同步刷新。试听热键与主题同样保存在本机，曲目与转换参数不落盘。

## 精度与校验口径

1. 组偏差：同一演奏组内各音符实际 Delay 与目标时刻之差的最大值。
2. 结束偏差：末组最后一个音符的落点与原曲时长之差。
3. 提前组：实际落点早于目标时刻的组数（应恒为 0）。
4. 判定阈值：单曲 ≤2 ms 视为通过，≤1 ms 视为逐组一致；超出即标注具体组号与偏差量。
5. 时间量化会引入不超过半个量化步长的预期误差，属参数语义而非转换误差。
6. 延音模式按音长推进，延时等于音长，与原曲拍距不逐组对齐，因此不产生组偏差；需要逐组贴合请切换「分组同按 + 按组间隔」。

## 处理与安全

1. 所有 MIDI 解析、转换、校验均在本机浏览器完成，文件不上传、不落盘、不经第三方统计。
2. 核心以密文分发，口令经高强度派生后解封，派生密钥仅在本机内存中使用，不写入任何持久存储。
3. 解封后校验核心完整性，与构建时记录不符即拒绝运行。
4. 核心载入后立即抹除全局引用，并在运行期周期性自检，被替换即终止会话。
5. 启用 Content-Security-Policy：禁止外链脚本、外部对象与表单提交，仅允许本站资源与 GitHub API 连接。
6. 拦截 F12 与开发者工具快捷键，第 3 次按下 F12 弹出安全警告（可选择继续或终止会话）。曲谱舱把 F12 作为停止键时，该次按键不计违规；网页无法阻止浏览器自身打开 DevTools，离开曲谱舱后仍由控制台探测、可视区域差与核心指纹三层复核。
7. 检测开发者工具控制台与可视区域异常，命中即清空核心并锁屏。
8. 未解锁状态下强行改 DOM 显示应用会被自动回滚。
9. 安全监测在密钥页即生效，未解锁也计数与拦截；窗口最小化 / 切后台不会误判。
10. 拦截 Ctrl+P（打印 / 另存 PDF）、Ctrl+S（保存网页）、PrintScreen 截图，并阻止页面拖拽导出。
11. 检测 iframe 嵌入，被第三方页面套用时立即终止显示，避免被仿站骗取密钥。
12. 站点策略文件（security.json）可下发口令吊销与设备限制清单，策略更新后立即生效。
13. 启用 Permissions-Policy：禁用摄像头、麦克风、定位、支付、USB、串口、HID、剪贴板读取与屏幕捕获，压缩能力面。
14. 30 天许可记录仅在本浏览器范围内绑定，不含任何个人身份信息；换机或换浏览器即失效并要求重新验证。

页面仅陈述防护层级与结果，不公开任何内部实现细节。使用许可密钥请向作者索取。
